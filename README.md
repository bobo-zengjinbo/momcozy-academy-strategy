# Momcozy Academy · Brand Strategy

Momcozy Academy 品牌视觉研究与设计策略网站。首期内容为孕产课程、女性健康与数字内容品牌的视觉竞品分析。

本项目是设计部门的策略与执行工作台，上游战略与内容规划来自：[2027 年课程体系建设规划](https://momcozy-course-plan-2027.vercel.app/)。首页通过“战略源站”模块标明两个网站的职责关系并提供直接入口。

## 当前内容

- 竞品定位象限
- 8 个品牌官网截图、来源地址与视觉解读
- 直接竞品、竞合对象和相邻标杆筛选
- 横向能力比较
- Momcozy 品牌机会与设计原则
- 后续视觉策略、视觉识别和应用验证模块入口

## 项目结构

```text
dist/
├── index.html
├── styles.css
├── script.js
└── assets/competitors/
```

该项目为纯静态 HTML、CSS 与 JavaScript。GitHub Pages 通过 `.github/workflows/pages.yml` 自动部署 `dist/`。
